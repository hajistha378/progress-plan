# Coco Lane Cafe — 11 Week Progress

This folder is a **separate progress-report copy**. The original raw website at `D:\Coco-Lane-Cafe` was not modified.

## Structure

- `index.html` — progress-report welcome page and 11-week menu
- `Week-01` … `Week-11` — progressive project stages
- Each week folder has `welcome.html` as its entry page
- `Week-11` contains the complete 11-page website, including `admin.html`

## What is in each week

| Week | Stage |
| --- | --- |
| 01 | Welcome page / project setup |
| 02 | Home page |
| 03 | Menu page |
| 04 | Product details |
| 05 | Cart system |
| 06 | Login and register |
| 07 | Checkout and WhatsApp |
| 08 | Order history and profile |
| 09 | Contact page |
| 10 | About page |
| 11 | Complete website including admin dashboard |

## How to demonstrate

1. Open `index.html` in this folder.
2. Choose a week from the week menu.
3. The welcome page for that week lists exactly which pages had been built.
4. Open `Week-11/welcome.html` to show the finished website, or use the live site: https://zainab0511.github.io/coco-lane-cafe/

## Technology

Frontend only: HTML5, CSS3 and vanilla JavaScript. Data is stored in browser LocalStorage. There is no PHP, MySQL, XAMPP or database connection.
